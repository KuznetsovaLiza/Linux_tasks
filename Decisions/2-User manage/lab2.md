# Лабораторная работа 2

## Задание 1: Управление пользователями

Сначала нужно войти в систему как root с помощью команды su -

```bash
[elizabeth@host-15 ~]$ su -
Password: 
[root@host-15 ~]# 
```

1. Добавление пользователей user1 и user2:
	- Добавление user1 с оболочкой bash:

	```bash
	[root@host-15 ~]# useradd -m -s /bin/bash user1
	```

	-m отвечает за создание домашней директории для пользователя, -s /bin/bash указывает, что для user1 будет использована оболочка по умолчанию bash

	- Добавление user2 с оболочкой sh:

	```bash
	[root@host-15 ~]# useradd -m -s /bin/sh user2
	```

	/bin/sh - установка в качестве оболочки по умолчанию sh

	- Установка паролей:
		- Для первого пользователя:

		```bash
		[root@host-15 ~]# passwd user1
		Enter new password: 
		Re-type new password: 
		passwd: all authentication tokens updated successfully.
		```

		- Для второго пользователя:

		```bash
		[root@host-15 ~]# passwd user2
		Enter new password: 
		Re-type new password: 
		passwd: all authentication tokens updated successfully.
		```

2. Назначение групп пользователям:
	- Назначение пользователю 1 группу администраторов:

		```bash
		[root@host-15 ~]# usermod -aG wheel user1
		```

		- usermod - команда для изменения пользователя, -aG: добавление (-a) пользователя в дополнительную группу (-G), wheel - название группы администраторов
		- без флага -a пользователь будет удален из всех других групп

	- Добавление user2 в группу user1:

		```bash
		[root@host-15 ~]# usermod -aG user1 user2
		```

3. Права доступа
	- Права доступа - это система правил, которая определяет, какие действия могут выполнять разные категории пользователей над файлами и директориями.
 
	- Права разделены для трех категорий:
		- Владелец (u) — пользователь, который создал файл/папку.
		- Группа (g) — группа пользователей, к которой принадлежит владелец.
		- Все остальные (o) — все прочие пользователи системы.

	- Для каждой категории можно назначать три типа прав:
		- Чтение (r) — для файлов: просмотр содержимого; для папок: чтение списка файлов.
		- Запись (w) — для файлов: изменение и удаление; для папок: создание и удаление файлов в ней.
		- Выполнение (x) — для файлов: запуск как программы/скрипта; для папок: возможность сделать ее текущей (cd).

	- Вывод прав доступа на файлы в текущей директории пользователя:

		```bash
		[root@host-15 ~]# ls -l
		итого 8
		drwxr-xr-x 2 root root 4096 сен 25 11:40 neeew
		drwx------ 2 root root 4096 сен 18 13:44 tmp
		```

	- Права пользователя user1:

		```bash
		[root@host-15 ~]# ls -ld /home/user1/
		drwx------ 8 user1 user1 4096 дек 21 14:55 /home/user1/
		```

		- Первый символ (- или d) показывает тип объекта: - — файл, d — директория.
		- Следующие 9 символов — это права доступа: первые 3 для владельца, следующие 3 для группы, последние 3 для всех остальных.

4. Изменение прав на файлы:
	- Изменить права на файл можно с помощью команды chmod:
		- Символический метод: chmod ugo+rwx filename (добавить (+) все права (rwx) для всех категорий пользователей (ugo)).
		- Цифровой (восьмеричный) метод: chmod 777 filename.

	- Создание файла, на который у всех пользователей будут все возможные права:
	
		```bash
		[elizabeth@host-15 ~]$ su - user1
		Password: 
		[user1@host-15 ~]$ echo "текст" > my_file.txt
		[user1@host-15 ~]$ chmod 777 my_file.txt
		[user1@host-15 ~]$ ls -l my_file.txt
		-rwxrwxrwx 1 user1 user1 11 дек 21 16:18 my_file.txt
		```

5. Учётная запись встроенного администратора - root.

6. Выполнение команды от имени администратора:
	- Выполнение одной команды с правами root: sudo <команда>. Необходимо, чтобы пользователь был в группе sudo.
	- Запуск новой оболочки с правами root: su - (требует пароль root).

7. Суперпользователь (root) не ограничен правами доступа внутри своей операционной системы. Он может делать что угодно с любыми файлами, процессами и настройками. Но у root существуют ограничения на уровне системы.

8. Удаление пользователя 2 с помощью пользователя 1:

	```bash
	[elizabeth@host-15 ~]$ su - user1
	Password: 
	[user1@host-15 ~]$ sudo userdel -r user2
	[sudo] password for user1:
	[user1@host-15 ~]$ id user2
	id: «user2»: такого пользователя нет
	```

	- Команда для удаления пользователя: userdel
	- Удаление домашней директории и почты пользователя: -r
	- Без флага -r - удаляется только учётная запись, файлы остаются

9. Изменение владельца папки: sudo chown user2 /home/user1/my_file.txt
	
	```bash
	[user1@host-15 ~]$ ls -l my_file.txt
	-rwxrwxrwx 1 user1 user1 11 дек 21 20:33 my_file.txt
	[user1@host-15 ~]$ 
	выход
	[elizabeth@host-15 ~]$ sudo chown user2 /home/user1/my_file.txt
	[sudo] password for elizabeth:
	[elizabeth@host-15 ~]$ su - user1
	Password: 
	[user1@host-15 ~]$ ls -l my_file.txt
	-rwxrwxrwx 1 user2 user1 11 дек 21 20:33 my_file.txt
	```

	- Новый владелец: user2
	- Путь к файлу: /home/user1/my_file.txt

# Лабораторная работа 2

## Задание 2: Запрещаем

1. Запрет входа для user1:

	```bash
	[root@host-15 ~]# usermod -L user1
	[elizabeth@host-15 ~]$ su - user1
	Password: 
	su: Authentication failure 
	```

2. Самый простой и распространенный способ — заблокировать учетную запись пользователя. Это можно сделать с помощью команды usermod -L ИМЯ_ПОЛЬЗОВАТЕЛЯ, которая блокирует пароль пользователя, сделав невозможным вход в систему с его помощью.

3. Другие способы запрета на вход для пользователя:
	- Изменение оболочки: sudo usermod -s /sbin/nologin user1 (или sudo usermod -s /bin/false user1). При попытке входа пользователь будет автоматически разлогинен.
	- Внесение в /etc/passwd: вручную изменить оболочку в файле /etc/passwd.
	- PAM: Настроить правила в /etc/pam.d/ для запрета доступа определенным пользователям или группам.

4. Можно ли создать пользователей с одинаковыми username?
	- В Linux username (имя пользователя) является уникальным идентификатором. Система не позволит создать двух пользователей с одинаковым username. При попытке выполнить useradd user1 второй раз вы получите ошибку: useradd: пользователь "user1" уже существует.

	```bash
	[root@host-15 ~]# useradd  user1
	useradd: пользователь «user1» уже существует
	```
